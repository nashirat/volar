# Volar for Omarchy 4

Install and apply with `omarchy theme install https://github.com/nashirat/volar.git`.

`colors.toml` drives Quattro's terminal, shell, editor, and Hyprland colors. `backgrounds/brown.jpg` is the wallpaper; `preview.png` is the switcher preview. The original Omarchy 1 config files remain in the repository for reference, but Quattro does not load them as theme settings. A theme installed from Git also cannot supply Lua files or terminal configs; Quattro generates those from `colors.toml`.
