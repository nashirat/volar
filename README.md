# Volar for Omarchy 4

Install and apply with `omarchy theme install https://github.com/nashirat/volar.git`.

`colors.toml` drives Quattro's terminal, shell, editor, and Hyprland colors. `backgrounds/brown.jpg` is the wallpaper; `preview.png` is the switcher preview. Quattro generates terminal, Neovim, and VS Code configs from the palette. The remaining Omarchy 1 files are kept for reference and are not loaded as Quattro theme settings.
