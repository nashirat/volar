# Volar for Omarchy 4

Install and apply with `omarchy theme install https://github.com/nashirat/volar.git`.

`colors.toml` defines the palette for the terminal, shell, editor, and Hyprland. Its focus accent and yellow use Gruvbox's gold (`#d8a657`), while the rest of Volar's palette remains intact. `shell.toml` uses that gold for focused controls and selected menu rows, and removes the outer border from the menu and launcher.

`backgrounds/1-the-backwater.jpg` is the first wallpaper from Omarchy's Gruvbox theme. `preview.png` is the original switcher preview. Quattro generates terminal, Neovim, and VS Code configs from the palette. The remaining Omarchy 1 files are kept for reference and are not loaded as Quattro theme settings.
